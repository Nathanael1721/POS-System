### Catatan Mimosa deep scan

3 hipotesis RBAC "inconclusive" diverifikasi manual dan BUKAN kerentanan:
void order menegakkan role di service layer (bukan middleware), media publik
by-design (UUID, non-sensitif), proxy Next memvalidasi origin backend.

## Yang diperiksa dan LOLOS

- **Auth**: login timing-safe (dummy bcrypt compare), pesan error generik, rotasi
  refresh (delete-then-issue), validasi issuer+type JWT, cost bcrypt 12.
- **RBAC**: semua route tulis produk/kategori/user/report/audit/store memakai
  `requireOwner`; kasir dibatasi ke data sendiri (order/shift) di service layer.
- **Upload gambar**: MIME + ukuran divalidasi **server-side** (bukan hanya frontend).
- **Error handler**: tidak membocorkan stack di produksi; 500 opaque + Sentry.
- **Media publik**: key UUID, tidak ada path traversal, Content-Type dari MIME tersimpan.
- **SQL**: seluruhnya parameterized (postgres.js tagged template), tanpa interpolasi.
- **Antislop hard gates**: R-24 nav semua valid; R-26 tanpa dead control; R-27
  empty/loading/error state lengkap; R-32 keyboard + focus (UA outline utk chip,
  ring khusus utk Button); R-17/18/36 tanpa klaim/statistik palsu; R-04 ikon
  lucide-style dipakai dengan alasan fungsional (scanability kasir, bukan dekorasi).
- **Login mobile & breakpoint** (R-03): diverifikasi ronde sebelumnya.
